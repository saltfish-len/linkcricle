# LinkCircle · 圆点遍历最短路径工具

上传一张含有圆点的图片（比如白底蓝点图），自动识别每一个圆，并计算出一条**遍历所有圆的最短路径**，直接画在图上。

纯 HTML + JavaScript 单文件实现，零依赖，所有计算都在浏览器本地完成，图片不会上传到任何服务器。

## 使用方法

直接用浏览器打开 `index.html` 即可：

- **点击 / 拖拽 / 粘贴**图片到画布区域
- 没有图片也可以点「生成示例图试一试」
- 识别或路径不理想时，可调节「识别灵敏度」和「最小圆面积」
- 支持开放路径（默认）和闭环路径（走完回到起点）两种模式
- 求解算法可选：快速近似（贪心 + 2-opt）或精确最优（动态规划，≤ 20 个圆）
- 结果图可一键下载

也可以直接部署到 GitHub Pages 在线使用。

## 实现原理

1. **圆识别**：采样图片四边像素估计背景色 → 与背景色差超过阈值的像素标为前景 → 8 连通域标记（洪泛填充）→ 按面积、宽高比、填充率过滤掉噪点和非圆形区域 → 每个连通域的质心即圆心，半径由面积反推。
2. **最短路径**：遍历所有点的最短路径是旅行商问题（TSP），属于 NP-hard。提供两种算法：
   - **快速近似**（默认）：从多个起点分别用最近邻贪心构造路径取最短，再用 2-opt 反复反转子路径优化到无法改进（带 2 秒超时保护），通常在最优解的几个百分点以内，点再多也很快；
   - **精确最优**：Held-Karp 动态规划，`dp[mask][j]` 表示访问完集合 `mask` 且停在 `j` 的最短长度，保证全局最优。复杂度 O(n²·2ⁿ)，限 20 个圆以内，超过自动回退到快速近似。
3. **绘制**：路径动画绘制，标出每个圆的访问顺序编号，起点为绿色。
