# LinkCircle · 圆点遍历最短路径工具

上传一张含有圆点的图片（比如白底蓝点图），自动识别每一个圆，并计算出一条**遍历所有圆的最短路径**，直接画在图上。

纯 HTML + JavaScript 单文件实现，零依赖，所有计算都在浏览器本地完成，图片不会上传到任何服务器。

## 使用方法

直接用浏览器打开 `index.html` 即可：

- **点击 / 拖拽 / 粘贴**图片到画布区域
- 没有图片也可以点「生成示例图试一试」
- 识别或路径不理想时，可调节「识别灵敏度」和「最小圆面积」
- 支持开放路径（默认）和闭环路径（走完回到起点）两种模式
- 求解算法可选：快速近似（贪心 + 2-opt）或精确最优（无数量限制，点多时慢慢算，可随时停止保留当前解）
- 结果图可一键下载

也可以直接部署到 GitHub Pages 在线使用。

## 实现原理

1. **圆识别**：采样图片四边像素估计背景色 → 与背景色差超过阈值的像素标为前景 → 对前景做距离变换（chamfer 3-4 两遍扫描近似欧氏距离）→ 取局部极大值作圆心候选（实心圆的圆心到背景的距离是局部最大，峰值恰好等于半径）→ 按半径从大到小做非极大值抑制去重 → 用圆盘内前景占比校验排除非圆形状。相比连通域质心方案，相切、重叠的圆各自保有自己的距离峰，能正确分离；相比霍夫圆变换更轻量（无需边缘检测和三维累加器），对实心圆点也更稳。
2. **最短路径**：遍历所有点的最短路径是旅行商问题（TSP），属于 NP-hard。提供两种算法，求解都在 Web Worker 中进行，不会卡住界面：
   - **快速近似**（默认）：从多个起点分别用最近邻贪心构造路径取最短，再用 2-opt 反复反转子路径优化到无法改进（带 2 秒超时保护），通常在最优解的几个百分点以内，点再多也很快；
   - **精确最优**：保证全局最优，没有数量上限。20 个圆以内用 Held-Karp 动态规划（O(n²·2ⁿ)，`dp[mask][j]` 表示访问完集合 `mask` 且停在 `j` 的最短长度），更多的圆自动切换为分支定界（用未访问点集最小生成树作下界剪枝，内存 O(n)）。搜索过程中找到的更短路径会实时画出来，并显示已证明下界和已探索分支数，搜索完成即证明最优；点很多时可能要等很久（NP-hard 的代价），可随时点「停止求解」保留当前找到的最短路径。开放路径通过添加一个到所有点距离为 0 的虚拟点转化为闭环问题求解。
3. **绘制**：路径动画绘制，标出每个圆的访问顺序编号，起点为绿色。
